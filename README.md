# Pose Match demo v1.2

瀏覽器試玩版：鏡頭畫出肢體骨架，對五個動作題限時計分，合格會提早 lock。完場有全畫面結算同動畫。v1.1 放寬咗「雙手叉腰」計分。v1.2 喺計分時用紅點標示未到位關節，完場可進入「挑戰題」：主持鎖定一個姿勢（只記關節，唔存影相），下一位跟住做。

## 點樣開

用 Chrome 或 Edge。唔好直接雙擊開檔（`file://` 多數開唔到鏡頭）。

```bash
cd 呢個資料夾
python3 -m http.server 8765
```

然後開 http://localhost:8765 ，允許鏡頭。姿勢模型已經放咗喺 `models/pose_landmarker_lite.task`，唔使每次再下載。MediaPipe 程式同 WASM 仍然由 CDN 載入，瀏覽器會 cache。

如果更新後畫面仲係舊版，請強制重新整理或清 cache。

## 操作

- 企入畫面約 1 秒，或撳「開始挑戰」／空白鍵：開始五題
- R：由頭再來（五題模式）
- 完場「挑戰題」：主持擺好姿勢，企定約 1 秒或撳「鎖定題目」；換人後撳「開始模仿」
- 唔會儲存影片或錄音；只將「今日最佳」（五題總分）記喺瀏覽器 localStorage
